# The Robot Apology

A two-line robot confession for the make.fun bounty: one sentence owning a specific, human-scale mistake, and one sentence naming the lesson it taught and the behaviour that changes because of it. The program reads `entry.txt` at runtime and writes it unchanged to the output directory, refusing to run if the text ever grows past the 400-character gate.
